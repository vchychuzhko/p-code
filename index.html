Where it all started?

Privacy Concern

  1. Claude has access to the OS
  2. Claude has access to applications
  3. Claude has access to user data

Security Concern

  1. If Claude is hacked, whole system might be compromised
  2. Claude can easily break something critical in the system

Should we do something?

Convenience vs Safety

  • Is this your personal or work PC?
  • Do you have any valuable or sensitive data on it?
  • Can you easily restore your system?

Options

  1. Dedicated PC (cloud or local)
  2. Docker
  3. Virtual Machine

My Setup

Connecting Filesystem

  1. Install virtiofsd
  2. Configure mounted folder
  3. Mount this folder in virtual machine
Instruction

How it works

  1. Project lives in shared folder
  2. shared folder is mounted to VM and Claude has access to it
  3. Host system is responsible for running the project

Pros

  1. Claude has access to only what you decide
  2. If Claude breaks anything, host system is unaffected
  3. Full compatibility between host and VM
  4. Easy to replicate
  5. You can turn it off

Connection to Claude

  1. Virtual Machine has static IP
  2. Add your key to authorized_keys
  3. Use alias for SSH connection

Demo

Cons

  1. Initial setup
  2. Extra steps with adding projects
  3. No IDE integrations
  4. CLI only

Summary

  • Decide if this is needed and worth it for you
  • Find the best setup that is suitable for you
  • Be responsible
